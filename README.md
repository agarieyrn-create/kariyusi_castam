# オリジナルかりゆしウェア デザイン開発システム

ブラウザだけで動く、かりゆしウェアのデザイン検討用プロトタイプです。
用途や雰囲気を入力し、3案の比較、実画像素材の選択、柄・配色・ロゴ位置の編集、模型によるサイズ感チェック、概算仕様書の保存まで確認できます。

## 使い方

1. `index.html` をブラウザで開く
2. 「条件入力」で用途、印象、基本色、モチーフ、予定枚数を選ぶ
3. 「提案」で3案を比較し、編集したい案を選ぶ
4. 「既存写真・素材」で参考画像を選び、編集プレビューへ反映する
5. 「編集」で柄密度、柄サイズ、衿型、ロゴ位置、ボタンを調整する
6. 「模型・サイズ」で身長、胸囲、肩幅などを入力し、推奨サイズとゆとり量を確認する
7. 「仕様書」で発注前の確認内容を保存する

## 主な機能

- 日本語UIの条件入力
- 既存画像フォルダのかりゆしウェア写真・素材ギャラリー
- 3方向のデザイン案生成
- SVGベースのシャツプレビュー
- 柄密度、柄サイズ、配色、衿、ボタン、ロゴ位置の編集
- 模型を使った正面・背面・横表示
- 胸まわり、肩幅、着丈差を使ったサイズ推奨
- 数量に応じた概算見積り
- 問い合わせ内容のブラウザ内保存

## ファイル構成

- `index.html`: 画面構成
- `styles.css`: レイアウトと見た目
- `scripts/config.js`: 初期設定
- `scripts/mock-db.js`: 配色、柄、素材、サイズ表のモックデータ
- `scripts/api-client.js`: セッション、提案、見積り、保存処理
- `scripts/renderers.js`: 画面描画、模型、仕様書の描画
- `scripts/app.js`: 画面操作と状態管理
- `デザイン写真/`: 参考写真と素材画像

## 注意

現時点ではブラウザ内で完結する試作環境です。正式運用には、画像生成API、データベース、問い合わせ送信、正式なサイズ表、製造仕様の承認フローを接続してください。
