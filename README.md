# オリジナルかりゆしウェア デザイン開発システム

ブラウザだけで動く、かりゆしウェアのデザイン検討用プロトタイプです。
用途や雰囲気を入力し、3案の比較、実画像素材の選択、柄・配色・ロゴ位置の編集、模型によるサイズ感チェック、概算仕様書の保存まで確認できます。

---

## 💻 動作環境

- Google Chrome (推奨) / Safari / Firefox 最新版
- ローカル開発環境: Node.js >= 18.0.0

---

## 🛠 セットアップと開発手順

### 1. 依存関係のインストール
プロジェクトのルートディレクトリで以下を実行します。
```bash
npm install
```

### 2. 環境変数の設定
`.env.example` をコピーして `.env` ファイルを作成し、必要な設定を行ってください。
```bash
cp .env.example .env
```

### 3. 開発サーバーの起動 (Vite)
ローカルで開発サーバーを起動し、ホットリロード有効な環境で動作確認を行います。
```bash
npm run dev
```
起動後、自動的または手動で `http://localhost:3000` をブラウザで開きます。

### 4. プロダクションビルド
静的ファイルを最適化して `dist/` ディレクトリへ出力します。
```bash
npm run build
```

## 🧪 テスト

### ユニットテストの実行
Vitest を用いたユニットテストを実行します。
```bash
npm test
```

### カバレッジの計測
```bash
npm run test:coverage
```

### 簡易スモークテストの実行
```bash
npm run smoke
```

## 📦 ファイル構成

- `index.html`: 画面のHTML構造
- `styles.css`: レイアウト、グラスモーフィズムデザイン、ダークモード、メディアクエリ
- `vite.config.js`: Vite用のビルド設定ファイル
- `scripts/config.js`: アプリケーションの動作モードや制限値の初期設定
- `scripts/mock-db.js`: 配色、柄、素材、サイズ表のモックデータ
- `scripts/api-client.js`: セッション生成、デザイン案生成、見積り計算、問い合わせ保存処理
- `scripts/renderers.js`: 画面描画、SVGシャツ、模型、仕様書等のレンダリングロジック
- `scripts/design-store.js`: デザインデータの永続化、共有URLの生成、URLデータ復元（検証付き）
- `scripts/fabric-editor.js`: Fabric.jsを用いた2Dロゴ・テキスト配置キャンバスエディタ
- `scripts/three-viewer.js`: Three.jsを用いたシャツとマネキンの3Dビジュアライザ
- `scripts/smoke-test.mjs`: ファイル存在性や基本設定を検証するスモークテスト
- `db/schema.sql`: PostgreSQL/Supabase向けの正規化データベース定義
- `db/seed.sql`: テスト用の初期投入シードデータ
- `tests/`: ユニットテストおよびE2Eテストコード
- `デザイン写真/`: ギャラリーで表示する写真・ロゴアセット類
- `3Dモデル/`: 3D表示で利用するテクスチャ・マネキン用アセット
