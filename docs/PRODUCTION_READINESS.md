# 本番運用移行計画書 (Production Readiness Guide)

本ドキュメントは、開発したオリジナルかりゆしウェアデザインシステムのプロトタイプを本番運用環境（Production）へ移行し、安全かつスケール可能な状態で運用するためのチェックリストおよびロードマップです。

---

## 🎯 優先度付き本番化チェックリスト

### 🔴 P0: リリースに必須（セキュリティ・致命的リスク）
- [ ] **APIキーの秘匿化（バックエンド移行）**:
  - フロントエンドから直接各種APIキー（OpenAI、Supabase Service Role）を呼び出すのを廃止。
  - バックエンドサーバー（Next.js API Routes / Node.js Express）経由で実行するように変更。
- [ ] **データベース接続のセキュア化**:
  - Supabase の RLS (Row Level Security) ポリシーを設定し、匿名ユーザーによるデータ書き換えや他ユーザーの問い合わせ・セッションデータの閲覧を防止。
- [ ] **SSL/TLSの強制化**:
  - 全通信を HTTPS (TLS 1.3推奨) で暗号化。常時SSL化の実施。
- [ ] **Content Security Policy (CSP) の設定**:
  - Webアプリケーションのセキュリティ保護のため、許可されたドメイン（自己、Three.js/Fabric.jsのCDNなど）からのリソース読み込みのみを制限するメタタグ・HTTPヘッダーを設定。

### 🟡 P1: 運用開始までに対応（パフォーマンス・信頼性）
- [ ] **CDNの導入とアセット最適化**:
  - 117枚のデザイン・素材写真を Cloudflare / AWS CloudFront などの CDN に配置し、WebP/AVIFへのフォーマット変換を自動化。
- [ ] **監視・ログツールの導入**:
  - **Sentry**: フロントエンドの実行時エラー、WebGL初期化エラーのリアルタイム収集。
  - **CloudWatch Logs / Papertrail**: サーバーサイドAPIのアクセスログ、AIエラーログの収集。
- [ ] **バックアップ & DR (災害復旧) 体制**:
  - Supabase データベースの自動日次バックアップ設定。
  - クラウドストレージ（R2/S3）の別リージョンへの世代管理バックアップ。
- [ ] **自動テストとCI/CDパイプライン**:
  - GitHub Actions を用いた、コードプッシュ時の Vitest テスト自動実行および Lint チェック。
  - Vercel / Netlify 等へのステージング/本番自動デプロイメントの構築。

### 🟢 P2: 安定稼働・継続改善（運用効率・UX）
- [ ] **GDPR / 個人情報保護法対応**:
  - お問い合わせで入力された個人情報（名前、メールアドレス）の暗号化保存（AES-256）。
  - プライバシーポリシーの明示と同意チェックボックスの設置。
  - 一定期間（例：商談終了後180日）経過後の個人情報の自動匿名化/論理削除バッチの構築。
- [ ] **WebGL非対応環境への完全フォールバック検証**:
  - 低スペック端末や企業内プロキシ等の制限によりWebGLが動作しない場合、SVGレンダラーへ自動的かつシームレスに切り替わるロジックの動作検証。

## 🔒 セキュリティ & プライバシー詳細計画

### 1. 個人情報 (PII) の保護と GDPR 準拠
本システムでは商談・ユニフォーム相談として、顧客名、会社名、メールアドレスを収集します。
- **データ保管**: データベース内の `inquiries` テーブルに保存する際、個人情報カラムは列レベル暗号化を実施。
- **データ削除要求 (Right to be Forgotten)**: 管理画面からユーザーIDを指定して、関連するすべての個人情報を完全に物理削除する機能を実装。

### 2. コンテンツセキュリティポリシー (CSP) 定義
レスポンスヘッダーまたはHTML内の `<meta>` タグで以下を厳密に制限します。
```http
Content-Security-Policy: default-src 'self'; script-src 'self' cdnjs.cloudflare.com cdn.jsdelivr.net 'unsafe-inline'; style-src 'self' 'unsafe-inline' fonts.googleapis.com; font-src fonts.gstatic.com; img-src 'self' data: blob:; connect-src 'self' *.supabase.co
```

## 📈 パフォーマンス・スケーラビリティ計画

- **画像の最適化**: 元画像（高解像度PNG）はデザイナーによる登録用とし、クライアントへの配信はViteビルドツールで最適化されたWebP（サムネイル用：横幅300px程度、プレビュー用：横幅800px程度）を動的に配信。
- **Three.jsのメモリマネジメント**: `three-viewer.js` が不要になったタイミング（セクション遷移時など）で、`geometry.dispose()`, `material.dispose()`, `texture.dispose()` を再起的に呼び出し、ブラウザのメモリリークを100%防止する。
