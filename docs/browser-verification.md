# ブラウザ検証記録

2026-08-15、Vite配信版をChromiumで `http://127.0.0.1:3000/` に接続して確認した。初期画面では6段階ナビゲーション、条件入力、3案の提案カード、素材ギャラリー、編集キャンバス、3D表示、見積・問い合わせ導線が表示された。提案更新状態は `role=status` のステータスバナーで表示され、再試行ボタンも存在する。

ブラウザコンソールにはThree.jsの将来の配信方式に関する非致命的な非推奨警告が1件あったが、3D表示の `rebuild()` と完了ログが確認でき、アプリ固有の例外や未処理エラーは確認されなかった。外部CDN障害時は3D側の既存フォールバック表示を維持する。
